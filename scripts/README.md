# Scripts

Shell helpers for local development, CI, and ad-hoc operations.

| Script            | Purpose                                               |
| ----------------- | ----------------------------------------------------- |
| `install.sh`      | Pull, pin, seed, and launch the toolkit; also provides the CI setup smoke test |
| `bump-versions.py` | Discover conservative Docker image update candidates |
| `check-framework-updates.py` | Check source-controlled framework dependencies |
